## 🔑 8. 语言版本与特性

| 特性 | 说明 |
|------|------|
| `LangVersion` | C# 9.0 |
| `#nullable enable` | 部分文件启用可空引用类型（如 `ICasbinDbContextProvider.cs`, `PolicyTypeContextProvider.cs`） |
| `IAsyncLifetime` | 集成测试使用 xUnit 异步生命周期 |
| `IClassFixture<T>` | 测试类共享夹具实例 |
| `ICollectionFixture<T>` | 测试集合共享夹具实例 |
| `partial class` | 核心适配器拆分为 2 个文件 |
| 泛型约束 | 广泛使用 `where TKey : IEquatable<TKey>`, `where TPersistPolicy : class, IEFCorePersistPolicy<TKey>, new()` |
