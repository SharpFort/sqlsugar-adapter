## 1. 项目概述

### 1.1 项目定位

**Casbin.NET.Adapter.EFCore** 是 [Casbin](https://casbin.org/) 授权框架的 Entity Framework Core 持久化适配器，负责将 Casbin 的策略（RBAC 规则）持久化到关系型数据库中。

### 1.2 核心能力

| 能力 | 说明 |
|------|------|
| **策略持久化** | 将 Casbin 内存模型中的策略（p, g, g2...）存储到 EF Core 支持的数据库 |
| **策略加载** | 从数据库加载策略到 Casbin 内存模型 |
| **多上下文支持** | 不同策略类型可存储到不同 Schema、表甚至不同数据库 |
| **事务原子性** | 共享 DbConnection 的多上下文可原子提交/回滚 |
| **AutoSave 模式** | 支持即时保存（默认）和批量保存两种模式 |
| **DI 集成** | `AddEFCoreAdapter<TKey>()` 一键注册到 ASP.NET Core 容器 |
| **多数据库** | 支持 SQLite、PostgreSQL、SQL Server 等所有 EF Core 兼容数据库 |
| **多目标框架** | net9.0~netcoreapp3.1 共 6 个 TFM |

## 3. 数据流概览

### 3.1 加载流程 (LoadPolicy)

```
多个 DbContext (去重)
  │
  ├─ context1 → GetCasbinRuleDbSet → AsNoTracking → ToList
  ├─ context2 → GetCasbinRuleDbSet → AsNoTracking → ToList
  └─ ...
  │
  └─ 合并 → OnLoadPolicy(store, allPolicies.AsQueryable())
            │
            └─ store.LoadPolicyFromPersistPolicy()
               │
               └─ Section 推断: Type[0] → "p" or "g"
```

### 3.2 保存流程 (SavePolicy)

```
IPolicyStore
  │
  └─ ReadPolicyFromCasbinModel → List<TPersistPolicy>
     │
     └─ GroupBy(p => GetContextForPolicyType(p.Type))
        │
        ├─ 共享连接? → SavePolicyWithSharedTransaction()
        │   ├─ connection.BeginTransaction()
        │   ├─ UseTransaction(transaction) 登记所有 context
        │   ├─ ExecuteDelete() 清空 + AddRange() 写入
        │   ├─ Commit / Rollback
        │   └─ UseTransaction(null) 清除
        │
        └─ 分离连接? → SavePolicyWithIndividualTransactions()
            └─ 每个 context 独立 BeginTransaction (非原子)
```
